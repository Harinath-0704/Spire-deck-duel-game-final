# ⚔️ Spire Deck Duel

A strategic card battle game built as a web application, featuring an interactive gameplay interface and online deployment.

🔴 **Live Demo:** https://spire-deck-duel-game-final-three.vercel.app/

---

## 📌 Project Overview

**Spire Deck Duel** is a card-based game project designed to provide an interactive and engaging battle experience through a modern web interface.

The project focuses on implementing game-related logic, user interaction, responsive UI design, and a structured frontend application.

It was developed as a practical project to strengthen my skills in modern web development, application architecture, and interactive game development.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/Harinath-0704/Spire-deck-duel-game-final.git
```

### 2. Navigate into the project

```bash
cd Spire-deck-duel-game-final
```

The application files are currently located inside:

```bash
Downloads/java-capstone-final
```

Navigate to the project folder:

```bash
cd Downloads/java-capstone-final
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open the application

Vite will provide a local development URL, normally similar to:

```text
http://localhost:5173
```

Open that URL in your browser.
